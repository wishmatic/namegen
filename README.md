# Namegen

RPG name generator with a decently good IRL name generator for Golang and JS, with an MCP server.

## MCP

To run the MCP server, deploy via Docker:

```sh
docker run -p 8080:8080 ghcr.io/wishmatic/namegen-mcp
```

## Go

```sh
go get github.com/wishmatic/namegen
```

### `name.Generate`

The core name generator.

```go
import (
	"github.com/wishmatic/namegen/gender"
	"github.com/wishmatic/namegen/name"
)

n := name.Generate(gender.Male, nil)
// => name.Name{ GivenName, Surname, Gender }
```

`gender` is one of `gender.Male`, `gender.Female`, or `gender.NonBinary`; an empty value is resolved at random. Pass a
`*name.Culture` to pin a culture, or `nil` to pick one at random.

## TypeScript

Note this is called "character-namegen", not "namegen".

```sh
pnpm add character-namegen
```

The package README (what npm shows) is [`ports/ts/README.md`](ports/ts/README.md).

## Scripts

The name lists are generated by the Python scripts in `scripts/`.

```sh
pip install -r scripts/requirements.txt
python scripts/generate_names.py
```

## Credits

The name lists are derived from the public sources below. We apply our own data transformation and cleaning on top of
them including deduplication, transliteration/romanization, vowel and length filtering, gender splitting, general
filtering, and quality control.

The data source is transformative and are not verbatim copies of the upstream data.
